## 📁 Cấu trúc thư mục

```
PROJECT_TEMPLATE/
├── README.md                  # Tổng quan project, hướng dẫn đọc docs
|
├── docs/                       # Tài liệu kỹ thuật, specs, datasheet
│   ├── specs.md                # Đặc tả kỹ thuật (yêu cầu, linh kiện, thông số)
│   ├── architecture.md         # Kiến trúc hệ thống (phân tầng, API contracts)
│   └── task_tracking.md        # Tracking công việc, tiến độ dự án
│
├── hardware/                   # Thiết kế PCB             
│   └── ...                   
│
├── firmware/                   # Firmware design
│   └── ...
│
├── software/                   # GUI or/and AI for USERS
│   └── ...
│
├── tools/                      # Scripts nội bộ: flash, calibration, test serial
│   └── ...
│
├── .gitignore                  # Lọc file biên dịch & IDE
├── PROJECT_RULES.md            # Convention on creating, naming files, folder and function 
└──  LICENSE
```

> Mỗi thư mục lớn (`firmware/`, `hardware/`, `software/`) có `README.md` riêng mô tả nội dung bên trong.
